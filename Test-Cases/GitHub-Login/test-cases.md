## TC001 - Valid Login

**Priority:** High

**Preconditions**
- User has a valid GitHub account.

**Steps**

1. Open GitHub.
2. Click **Sign in**.
3. Enter a valid username.
4. Enter a valid password.
5. Click **Sign in**.

**Expected Result**

- User logs in successfully.
- Dashboard is displayed.

---

## TC002 - Invalid Password

**Priority:** High

**Preconditions**
- User has a valid username.

**Steps**

1. Open GitHub.
2. Click **Sign in**.
3. Enter a valid username.
4. Enter an incorrect password.
5. Click **Sign in**.

**Expected Result**

- Login fails.
- Error message is displayed.
